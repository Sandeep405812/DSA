---

## 📂 Repository Structure

```
DSA/
├── 1.C++ STL/
│   ├── pair.cpp            # C++ STL pair usage & manipulation
│   └── vector.cpp          # Dynamic arrays, iterators & common STL algorithms
└── Array/
    ├── check_sorted.cpp    # Linear scan array sorted check (O(N))
    ├── largest.cpp         # Finding maximum element in an array
    └── second_largest.cpp  # Optimal single-pass second largest element search
```

## 🛠️ How to Compile & Run

Using any standard `g++` or `clang++` compiler:

```bash
# Compile
g++ -std=c++17 Array/second_largest.cpp -o second_largest

# Run
./second_largest
```
